# zsh configuration

Cross-platform zsh setup managed with chezmoi.

## Tools

### Required

These are needed for the shell to initialize properly.

| Tool                                            | Purpose                            | Install                                                                                           |
| ----------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------- |
| [homebrew](https://brew.sh)                     | Package manager, provides fzf path | `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"` |
| [antidote](https://github.com/mattmc3/antidote) | Plugin manager                     | Auto-clones on first shell start                                                                  |
| [starship](https://starship.rs)                 | Prompt                             | `brew install starship`                                                                           |
| [zoxide](https://github.com/ajeetdsouza/zoxide) | Smart cd                           | `brew install zoxide`                                                                             |
| [fzf](https://github.com/junegunn/fzf)          | Fuzzy finder                       | `brew install fzf`                                                                                |

### Optional (aliased)

Shell works without these - aliases just won't work.

| Tool                                        | Alias/Function         | Purpose               | Install                                  |
| ------------------------------------------- | ---------------------- | --------------------- | ---------------------------------------- |
| [micro](https://micro-editor.github.io)     | `mi`, `$EDITOR`        | Simple editor         | `brew install micro`                     |
| [eza](https://github.com/eza-community/eza) | `ls`, `ll`, `la`, `lt` | Modern ls             | `brew install eza`                       |
| [gomi](https://github.com/b4b4r07/gomi)     | `rm`                   | Safe delete (trash)   | `brew install gomi`                      |
| [yazi](https://github.com/sxyazi/yazi)      | `y`                    | Terminal file manager | `brew install yazi`                      |
| [VS Code](https://code.visualstudio.com)    | `e`                    | GUI editor            | `brew install --cask visual-studio-code` |
| pnpm                                        | `pn`, `dlx`            | Package manager       | `brew install pnpm`                      |

### Initialized if present

These are sourced/initialized only if installed.

| Tool | Purpose     |
| ---- | ----------- |
| bun  | Bun runtime |

### Local only

Defined in `*.local.zsh` files (not synced).

| Tool       | Alias/Function                                            | Purpose          |
| ---------- | --------------------------------------------------------- | ---------------- |
| wezterm    | `wez-theme`, `wez-themes`, `wez-theme-set`, `wez-connect` | Terminal theming |
| claude-mem | `claude-mem`                                              | Memory plugin    |

## File structure

```
~/.zshrc                    # Main config (template for chezmoi)
~/.config/zsh/
├── aliases.zsh             # Portable aliases [synced]
├── aliases.linux.zsh       # Linux/Debian aliases [synced]
├── aliases.local.zsh       # Local-only aliases [NOT synced]
├── env.zsh                 # Portable env vars [synced]
├── env.local.zsh           # API keys, local paths [NOT synced]
├── plugins.txt             # Antidote plugin list [synced]
├── plugins.zsh             # Generated by antidote [not synced]
├── CLAUDE.md               # Local context [not synced]
└── README.md               # This file [synced]
```

## Bootstrap on new machine

```bash
# Install homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install chezmoi and apply dotfiles
sh -c "$(curl -fsLS get.chezmoi.io)" -- init --apply YOUR_GITHUB_USERNAME

# Install required tools
brew install starship zoxide fzf

# Install optional tools
brew install micro eza gomi yazi pnpm
```
